## 1. Реализованный базовый датчик случайных чисел

### Линейный конгруэнтный генератор (LCG)

Суть алгоритма заключается в использовании **модульной арифметики** для вычисления последовательности чисел. Каждое следующее число $X_{n+1}$ вычисляется на основе предыдущего $X_n$ по формуле:

$$X_{n+1} = (a \cdot X_n + c) \pmod{m}$$

#### Параметры формулы:

- **$X_0$ (Seed / Зерно):** Начальное значение, с которого начинается генерация.
- **$a$ (Множитель):** Константа, на которую умножается текущее число. В реализации: `1 664 525`.
- **$c$ (Приращение):** Константа, которая добавляется после умножения. В реализации: `1`.
- **$m$ (Модуль):** Максимальный диапазон значений. В реализации: $2^{32} = 4\ 294\ 967\ 296$.

### Реализация на C#

```csharp
class LCG
{
    private long _state;
    private const long M = 4294967296L; // 2^32
    private const long A = 1664525L;
    private const long C = 1L;

    public LCG(long seed = 42) => _state = seed;

    public double Next()
    {
        // Формула: X_{n+1} = (a * X_n + c) % m
        _state = (A * _state + C) % M;
        // Приведение к интервалу [0, 1)
        return (double)_state / M;
    }
}
```

#### Почему в интервале [0, 1)?

Результат операции $\pmod{m}$ всегда находится в диапазоне $[0,\ m-1]$, поэтому для получения значения $\alpha$ на интервале $[0, 1)$ результат делится на модуль:

$$\alpha = \frac{X_{n+1}}{m} \in [0,\ 1)$$

#### Почему «Псевдослучайный»?

- **Детерминированность:** Зная $X_0$ и параметры, можно предсказать все последующие числа.
- **Периодичность:** Рано или поздно последовательность начнёт повторяться. Хороший датчик должен иметь очень большой период.
- **Воспроизводимость:** Используя одно и то же зерно (seed), можно получить идентичную последовательность — критично для отладки моделей.

## 2. Вычисление выборочных средних и дисперсий

Размер выборки: **N = 100 000 значений.** Статистики вычисляются для двух источников: собственного LCG-генератора и встроенного `Random` из стандартной библиотеки C#.

```csharp
static (double mean, double variance) GetStats(double[] sample)
{
    double mean = sample.Average();
    double variance = sample.Average(x => (x - mean) * (x - mean));
    return (mean, variance);
}

// Теоретические значения для равномерного U[0, 1]
double theoreticalMean = 0.5;
double theoreticalVar  = 1.0 / 12.0; // ≈ 0.08333
```

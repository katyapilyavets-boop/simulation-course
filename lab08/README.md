# Пуассоновский поток. События на сервере

> Моделирование потока заявок на сервер с использованием распределения Пуассона

## Задание

- **Событие** — поступление заявки на сервер;
- **Определить** число заявок за интервал времени `T`;
- **Построить** распределение числа заявок;
- **Вычислить** среднее и дисперсию;
- **Сделать вывод** о соответствии потока пуассоновской модели.

## Математическая модель

### Пуассоновский поток заявок

```
P(X = k) = (λT)^k · e^(-λT) / k!
```

| Параметр | Описание | Пример |
|----------|----------|--------|
| `λ` | Интенсивность потока (заявок/сек) | 2.5 заявки/сек |
| `T` | Интервал наблюдения (сек) | 10 сек |
| `λT` | Ожидаемое число заявок за интервал | 25 заявок |
| `k` | Фактическое число заявок | 0, 1, 2, ... |

### Ключевое свойство для проверки

```
Для распределения Пуассона:
  Среднее (μ) = Дисперсия (σ²) = λT
  
  → Критерий: σ² / μ ≈ 1
```

## Реализация

### Алгоритм симуляции

```csharp
// Один эксперимент: генерация событий через экспоненциальные интервалы
private int SimulateSingleRun(double lambda, double T)
{
    double t = 0;
    int count = 0;
    
    while (true)
    {
        // Экспоненциальное распределение: время до следующей заявки
        double dt = -Math.Log(1.0 - rng.NextDouble()) / lambda;
        t += dt;
        if (t > T) break;  // Вышли за интервал?
        count++;           // Заявка принята
    }
    return count;
}
```

### Статистическая обработка

```csharp
// Вычисление выборочных характеристик
double mean = data.Average();  // Среднее
double variance = data.Select(x => Math.Pow(x - mean, 2)).Average();  // Дисперсия
double ratio = variance / mean;  // Критерий Пуассона
```

### Визуализация

- **Гистограмма** — эмпирическая частота получения `k` заявок
- **Кривая Пуассона** — теоретические вероятности `P(X=k)` при заданном `λT`
- **Сравнение** — наложение графиков для визуальной оценки соответствия


## Интерпретация результатов

### Пример вывода

```
Параметры: λ = 2.5, T = 10.0 → λT = 25.0
Экспериментов: N = 10 000

Результаты:
  • Среднее:        24.9873
  • Дисперсия:      25.1204
  • Станд. отклонение: 5.0120
  • Дисп / Среднее: 1.0053
  
Вердикт: ✓ Пуассоновский поток подтверждён
```

### Критерии вывода

| Отношение `σ²/μ` | Вывод |
|-----------------|-------|
| `0.95 – 1.05` | ✓ Поток соответствует пуассоновской модели |
| `0.90 – 0.95` или `1.05 – 1.10` | ⚠ Незначительное отклонение (возможно, малое `N`) |
| `< 0.90` или `> 1.10` | ✗ Поток не является пуассоновским (проверьте параметры или модель) |


## Примечания

1. **Воспроизводимость**: для фиксированных результатов инициализируйте генератор константой:
   ```csharp
   private Random rng = new Random(42);
   ```

2. **Производительность**: при `N > 50 000` используйте `Parallel.For` для ускорения симуляции.

3. **Точность**: отношение `σ²/μ` сходится к 1 со скоростью `O(1/√N)` — увеличивайте `N` для более строгих выводов.

4. **Валидация**: дополнительно можно применить χ²-тест согласия для количественной оценки соответствия.


**Итог**: Приложение позволяет эмпирически проверить фундаментальное свойство пуассоновского потока — равенство среднего и дисперсии — и визуализировать распределение числа заявок на сервер за заданный интервал времени.

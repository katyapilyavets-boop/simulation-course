# Отчет по лабораторной работе №5

## Тема: Разработка стохастических приложений с графическим интерфейсом на базе LCG

### 1. Цель работы

Создание интерактивного приложения для моделирования случайных событий с использованием собственного базового датчика случайных чисел. Реализация двух режимов: бинарного выбора (Да/Нет) и классического «Магического шара».

### 2. Реализация базового датчика случайных чисел

```c#
class LCG
{
    private long _state;
    private const long M = 4294967296L;
    private const long A = 1664525L;
    private const long C = 1L;

    public LCG(long seed = 42)
    {
        _state = seed;
    }

    public double Next()
    {
        _state = (A * _state + C) % M;
        return (double)_state / M;
    }
}
```

### 3. Реализация алгоритма для магического шара

```c#
 private int RandomEventFromGroup(double[] probs)
 {
     double A = _lcg.Next(); 
     int k = 0;              

     while (k < probs.Length - 1)
     {
         A = A - probs[k];   
         if (A <= 0)         
             return k;       
         k++;                
     }

     return k; 
 }
 ```
 ### 4. Реализация алгоритма для бинарного выбора (Да/Нет)

```c#
 private bool RandomEvent(double p)
{
    double alpha = _lcg.Next();
    return alpha < p;
}
```

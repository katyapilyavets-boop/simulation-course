##Выводы
1. Когда мы разбили пластину всего на два участка (шаг 0.1 м), расчёт дал неверный результат — 50°C, то есть просто температуру с края. Это как пытаться нарисовать плавную линию, имея только две точки: деталей не видно, результат неточный.

2. Чем меньше шаг по пространству, тем стабильнее и правдоподобнее становится ответ: температура плавно снижается и «устаканивается» около 23,8°C. Это хороший знак — значит, метод работает и стремится к правильному решению.

3. Та же история: при более мелком шаге по времени результат тоже перестаёт «скакать» и сходится к тому же значению ~23,8°C. При этом, начиная с определённого момента, дальнейшее уменьшение шага почти не меняет ответ (разница менее 0,01°C) — значит, мы уже достигли достаточной точности.

4. Самый точный результат (23,77°C) получается при очень мелких шагах, но это требует больше вычислений. Если вам достаточно точности до 0,01°C, можно смело использовать более крупные шаги (dx = 0,001 м, dt = 0,001 с) — результат будет 23,79°C, а расчёт пройдёт быстрее.
   
Главный итог:
Наш численный метод работает правильно: при уточнении сетки и шага по времени результаты стабильно сходятся к одному значению. Это подтверждает, что алгоритм реализован верно и ему можно доверять для решения задач теплопроводности.

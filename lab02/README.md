## Выводы
1. Проблема грубой дискретизации: При шаге по пранстранству 0.1 м, расчёт дал неверный результат — 50°C, то есть просто температуру с края. Неточность расчетов из-за грубой пространственной дискретизации.

2. Сходимость по пространству: Чем меньше шаг по пространству, тем стабильнее и правдоподобнее становится ответ, температура плавно снижается и «устаканивается» около 23,8°C. 

3. Сходимость по времени (аналогично): при мелком шаге по времени результат перестаёт «скакать» и сходится к тому же значению ~23,8°C. При этом, начиная с определённого момента, дальнейшее уменьшение шага почти не меняет ответ (разница менее 0,01°C) — достаточная точность.

4. Оптимальные параметры расчёта: наиболее точное решение ~23,77°C получено при наименьших шагах dx=0.0001 м и dt=0.0001 с. Для практических расчётов с точностью до 0.01°C достаточно использовать шаги dx=0.001 м и dt=0.001 с, что даёт значение температуры ~23,786°C.
   
Главный итог:
Численный метод демонстрирует устойчивую сходимость как по пространству, так и по времени, что подтверждает корректность реализации алгоритма решения одномерного уравнения теплопроводности методом конечных разностей.
